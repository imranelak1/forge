# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-selected: Next.js, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, Recharts, Lucide; FastAPI, Pydantic, SQLAlchemy, Alembic, PostgreSQL. Docker Compose for local use.

## Users

Software development teams investigating engineering delivery and configuring pipeline responses.

## Product Purpose

Forge connects engineering activity, traces software lifecycles and turns measured changes into explainable insights and auditable automation.

## Operating Context

Issue → pull request → commits → CI → tests → deployment → production errors. Initial sources: GitHub, Actions, JUnit and Sentry. Organization isolation is mandatory.

## Capabilities and Constraints

Phase 0 was approved with the user's “go” instruction. Implement Phase 1 only, then stop. This phase supplies a running application foundation and genuine health checks; authentication, integrations, customer data and metrics remain future work. No fabricated metrics, fake functioning controls or unimplemented provider connections.

## Brand Commitments

Forge. Dark-first, professional developer-tool interface; subtle borders, dense readable data layouts, excellent spacing, color mainly for state. These constraints are explicit in the user's brief.

The user authorized the public landing at `/` with a central dimensional pipeline track. One coral commit carrier follows two metallic rails through GitHub, Actions, JUnit and Sentry checkpoints. The track draws itself, opens a branch for reproduction, returns to the related change for investigation and switches into human review. Motion follows connected routes. Realistic code/event previews, fast Anime.js text reveals and the Anime.js warm charcoal/coral palette remain. Integrations and automation are in development; examples are illustrative. `/app` retains its existing dark foundation, and the 3D logo and Phase 2 backend remain separate work.

## Evidence on Hand

The approved architecture and milestone contracts live in docs/. No customer history, identities, commercial claims or production deployment exists.

## Product Principles

- Show the evidence behind each insight.
- Preserve missing data and uncertainty.
- Keep tenant authorization at every boundary.
- Make pipeline responses inspectable and retry-safe.

## Open Decisions

Production hosting and provider account details are deferred to their scheduled phases. Typography and precise spacing are implementation choices within the approved visual brief.
