# Landing page - the SVG delivery path

Mode: Persuade.

## Direction contract

THESIS: Forge turns separate engineering events into traceable evidence and deliberate responses.

OWN-WORLD: Warm charcoal canvas, off-white type, coral controls, warm stone integrations, existing Geist and stable coral/orange/lime/cyan/blue source identities. The user-selected Anime.js palette supersedes the initial monochrome build. App palette and wordmark remain unchanged.

STORY: One checkout commit follows an SVG line between GitHub, Actions, JUnit and Sentry. The marker traces delivery, returns to a regression test, returns to the related code and ends at human review. The original tests pass before the error; the regression test is a later reproduction. Code previews and integrations remain explicitly illustrative/planned.

FIRST VIEWPORT: A partly drawn line, commit marker and authentic tool logos sit beneath the centered headline. The working-platform CTA and story progress remain discoverable.

FORM: A clean, centered SVG path uses Anime.js createDrawable and createMotionPath. Scroll draws and follows the line; reverse scroll retraces the journey. Native logo controls select code examples. Anime.js splitText animates heading characters through clipped words and reveals explanatory words, settling within 620ms. Reduced motion and no JavaScript retain readable text and the complete SVG.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
